# BlinkIT Grocery Sales Dashboard(Interative Dashboard using Power BI)

## Project Objective
The main objective of this project is to use Power BI and data analytics techniques to transform raw grocery sales data into an interactive business intelligence dashboard that supports data-driven analysis.

## Dataset used
- <a href="https://github.com/chakradharreddy95/POWER-BI-Dashboard/blob/main/BlinkIT%20Grocery%20Data%20(1).xlsx">Dataset</a>
## Questions (KPIs)
- What is the total sales and average sales?
- Which item categories generate the highest sales?
- Which outlet type has the highest sales?
- Which outlet location has the highest sales?
- How does sales performance vary by outlet size?
- Which fat-content category contributes more to sales?
- How do customer ratings vary across different outlets?
- How has sales performance changed based on outlet establishment
