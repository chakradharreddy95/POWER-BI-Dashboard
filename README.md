# BlinkIT Grocery Sales Dashboard(Interative Dashboard using Power BI)

## Project Objective
The main objective of this project is to use Power BI and data analytics techniques to transform raw grocery sales data into an interactive business intelligence dashboard that supports data-driven analysis.

## Dataset used
- <a href="https://github.com/chakradharreddy95/POWER-BI-Dashboard/blob/main/BlinkIT%20Grocery%20Data%20(1).xlsx">Dataset</a>
## Questions (KPIs)
- What is the total sales and average sales?
- Which item categories generate the highest sales?
- Which outlet type has the highest sales?
- Which outlet location has the highest sales?
- How does sales performance vary by outlet size?
- Which fat-content category contributes more to sales?
- How do customer ratings vary across different outlets?
- How has sales performance changed based on outlet establishment

  ## Process
- Data Preparation: Imported the BlinkIT grocery sales dataset from Excel into Power BI and reviewed the data for missing, duplicate, and   inconsistent values.
- Data Cleaning & Transformation: Used Power Query to clean the dataset, handle missing values, standardize data types, and prepare       fields for analysis.
-  Data Modeling: Structured the dataset and created the required relationships and analytical fields for dashboard development.
- DAX & KPI Development: Created DAX measures for Total Sales, Average Sales, Number of Items, and Average Rating to track key business  metrics.
- Data Visualization: Developed charts and KPI cards to analyze sales performance across Item Type, Fat Content, Outlet Type, Outlet Size, and Location.
- Interactive Dashboard: Added slicers, filters, and interactive visuals to enable dynamic exploration of sales and outlet-level performance.
- Insight Generation: Analyzed the dashboard to identify sales trends, high-performing categories, and outlet performance patterns.
